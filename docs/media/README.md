# Product walkthrough

The finished film is distributed through the [Product walkthrough](https://github.com/maccydee/remote-fleet-agent/releases/tag/showcase-v5). The film demonstrates software version **0.9.0**. Video binaries stay in release assets to keep the source clone small.

- Full film: 153 seconds, 1920 × 1080, 30 fps, H.264 with AAC stereo.
- Smaller preview: 1280 × 720, with the same runtime and audio.
- SRT and WebVTT captions are included alongside the files. The supporting text also appears in the picture.
- The repository poster is the supplied frame at 93.5 seconds.

The film presents a recorded Claude Code conversation and workspace interactions with fictional clients and simulated devices. Tool calls are condensed; simulation and illustration labels are retained. The opening 30-device illustration is separate from the 11-device recorded demo. A simulated repair does not establish a native endpoint repair. The recorded assistant's wording is retained; the current controller dispatches sequentially within the approved batch ceiling.
