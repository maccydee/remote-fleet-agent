# Support release evidence

Every release claim needs a dated result and an artifact link. Keep private endpoint evidence outside source control. Use PASS, FAIL, BLOCKED and NOT_RUN explicitly; a pytest skip for missing prerequisites means no native proof.

| Gate | Required result | Current evidence limit |
|---|---|---|
| Operations UI | Real DOM navigation, filtering, case and approval tests | Record actual current browser suite results |
| Administration enforcement | Scope, identity, digest, actor, expiry, crash and unknown-state tests | Unit/fake transport proof is not native repair proof |
| Windows endpoint | Current DESKTOP-6PB6U6S enrollment, exact approved scratch change/check/recovery/cleanup | New native cycle NOT_RUN without current manifest and human decisions |
| Linux endpoints | Two actual Docker SSH endpoints, scratch cycle, failed canary, uncertain-dispatch stop | Container evidence excludes systemd, kernel and GUI claims |
| macOS endpoint | Actual enrolled SSH account, context and approved scratch cycle | Local shell execution does not establish SSH support |
| Controller hosts | Python/API/MCP/wheel results on Windows, macOS and Linux separately | One controller targeting three OSes is not a 3×3 matrix |
| AI clients | SDK transport plus actual installed-client interactions | Config generation does not prove interactive support or human approval |
| Upgrade/restore | Copied old records, preserved authority, isolated backup restore | Never automatically execute historical approvals |
| Marketing | Existing passing artifacts, inspected footage and human privacy review | Capture success does not make footage publishable |

Native preflight tests prove enrolled scope and observed pinned SSH identity only. Scratch script tests run in local disposable temporary directories and validate sentinel/cleanup rules. Keep these separate from native administration execution in the result report.

Record the exact command, date, interpreter/dependency versions, source revision or diff hash, elapsed time, test counts, skips and limitations. Link the plan digest, authenticated human decision, remote results and cleanup result for endpoint changes. Unknown completion remains uncertain even after a controller restart.

Public screenshots and recordings must come from verified fictional workflows with visible Simulation labels, or from separately approved native material. Keep source recordings and pending/failed scenes private. Capture tooling cannot approve its own footage, and this document grants no publication authority.
